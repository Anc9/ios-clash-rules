# 修改前后的验证清单

## 配置结构
- [ ] YAML 语法正确（`python scripts/validate.py`）
- [ ] 所有 RULE-SET 均有同名 rule-provider
- [ ] 所有代理策略均有同名 proxy-group，MATCH 是最后一条
- [ ] 文件不包含订阅 URL、密码、UUID 或实际代理节点

## iOS 真机
- [ ] 机场订阅刷新后，新增/删除的节点同步到对应地区
- [ ] 香港、日本、美国等地区分组有正确节点，免费/下载专用线路未误入
- [ ] `url-test` 能显示延迟、不可用节点不会被选中
- [ ] 普通国外网站按「🚀 代理选择」走代理
- [ ] AI 服务命中「🤖 AI 服务」，更改策略后正确生效
- [ ] 国内常用应用正常直连
- [ ] 银行与支付 App 正常访问（VPN 检测不一定受 DIRECT 控制）
- [ ] 「🛡 广告拦截」REJECT/DIRECT 切换正常，无关键页面误拦
- [ ] MRS 规则集首次下载与更新正常
- [ ] 停用新规则并切回原始配置的回滚路径可用

## 故障排查
先确认「配置库」当前使用的则方案，再查看「最终运行配置」和连接日志。不要在无法启动时删除原订阅。
